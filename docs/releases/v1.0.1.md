# TekaFlow 1.0.1: o app volta a abrir

Versão 1.0.1  
21 de Novembro de 2026  
Baixe o `.zip` desta versão, arraste o TekaFlow para Aplicativos e, na primeira abertura, clique com o botão direito e escolha Abrir. A 1.0.0 não abria e deve ser substituída.

## ⭐ Destaques

- O app abre normalmente no Mac.
- Cada versão nova passa por um teste de abertura antes de ser publicada.

## 🛠️ Correções

- **Abertura do app:** Corrigimos o aplicativo, que não abria na 1.0.0 por causa do banco de dados local. Quem baixou a 1.0.0 precisa baixar esta versão, porque a atualização automática não alcança esse problema.
- **Publicação das versões:** Corrigimos o preparo da release, que agora monta o banco de dados para o app e confere a abertura antes de publicar.
